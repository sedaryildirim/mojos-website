# Mojo's website

Mojo's, rock 'n' roll burgers: 4 branches on 2 islands (Chaloklum and Thong Sala on Koh Phangan, Lamai and Nathon on Koh Samui).

A static one-page site with no build step: `index.html`, `css/`, `js/` (GSAP, ScrollTrigger and Lenis in `js/vendor/`), `fonts/` (self-hosted) and `img/`. GitHub Pages serves it from `main`.

It is a preview for now: `robots.txt` and the robots meta tag keep search engines away until it moves to its own domain. The design source is in the CDC Google Drive, under `Websites/Mojos/` (`PRODUCT.md`, `DESIGN.md` and the mock-ups).
